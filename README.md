# Data Science for Linguists FS2026
Welcome to our class repository. This shared guide is designed to help you use Markdown, R, and GitHub in data science projects. It serves two main purposes: first, to give you hands-on experience collaborating on GitHub through a meaningful, large-scale task; and second, to build a collective resource of best practices for your group work.

## Overview
Each of you will contribute to the project library by selecting a topic and editing a corresponding section of the document. A list of topics is available in the [Task List](https://github.com/UZH-Linguistic-Data-Science-Class-2026/project-lib/issues/1), and you’re welcome to propose additional ones if you notice that something is missing. Everyone must complete one task. This is a mandatory activity required for successfully completing the course.

We will follow a branch-based workflow. You’ll make your contributions in separate branches and request my approval before merging your changes into the main document. This process helps maintain the quality and consistency of the final product.

## Workflow
1. Familiarise yourself with branch workflows as explained on the class slides.
2. Pick one task from the [Task List](https://github.com/UZH-Linguistic-Data-Science-Class-2026/project-lib/issues/1).
3. Comment on the [Task List](https://github.com/UZH-Linguistic-Data-Science-Class-2026/project-lib/issues/1) discussion, specifying the task you would like to complete.
4. Create a branch named `tasks/your-name-task-description`
5. Make your changes to project-lib.Rmd
6. Submit a pull request
7. Fix any merge conflicts with the remote `main` branch
8. Wait for review and approval
